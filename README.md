# 数字化献血志愿者招募平台（MVP 第一版）

一个可本地运行、可页面演示、展示完整业务闭环的献血志愿者招募平台 Demo。

技术栈：**FastAPI + Vue3 + Element Plus + ECharts + SQLite**，后端运行于 Conda 环境 `xueye`（Python 3.11）。

核心演示闭环：

> 用户注册登录 → 完善个人信息 → 提交献血预约 → 填写健康征询表 → 管理端处理预约 → 用户提交反馈评价 → 管理端查看统计图表 → 外部接口返回模拟数据

---

## 一、目录结构

```
xueye/
├── backend/                 # FastAPI 后端
│   ├── app/
│   │   ├── core/            # 配置、数据库、安全、依赖
│   │   ├── models/          # SQLAlchemy 数据模型
│   │   ├── schemas/         # Pydantic 模型
│   │   ├── routers/         # 各业务模块接口
│   │   ├── seed.py          # 演示数据初始化
│   │   └── main.py          # 应用入口
│   ├── environment.yml      # Conda 环境定义
│   └── requirements.txt
└── frontend/                # Vue3 + Element Plus 前端
    └── src/
        ├── api/             # axios 封装
        ├── router/          # 路由 + 登录拦截
        ├── store/           # Pinia 状态管理
        └── views/           # 页面（user / admin / group）
```

## 二、环境准备与启动

### 1. 后端（FastAPI）

```bash
# 创建并激活 Conda 环境
conda create -y -n xueye python=3.11
conda activate xueye

# 安装依赖
cd backend
pip install -r requirements.txt

# 初始化演示数据（首次运行）
python -m app.seed

# 启动后端（默认 http://127.0.0.1:8000）
uvicorn app.main:app --reload --port 8000
```

- 接口文档（Swagger）：http://127.0.0.1:8000/docs
- 应用启动时会自动建表并写入管理员账号、采血地点、团体申报示例。
- 运行 `python -m app.seed` 会额外写入测试用户和示例预约/反馈/评价数据。

### 2. 前端（Vue3）

```bash
cd frontend
npm install
npm run dev   # 默认 http://127.0.0.1:5173
```

前端通过 Vite 代理把 `/api` 转发到后端 `http://127.0.0.1:8000`，无需额外配置跨域。

## 四、功能演示顺序

1. 打开系统首页 `/`
2. 注册普通用户（或用测试账号登录）
3. 登录后完善「我的个人信息」
4. 提交「我要预约献血」
5. 在「我的预约」查看预约记录
6. 填写「健康征询表」（预约状态变为「已填写健康征询表」）
7. 退出，使用管理员登录管理端
8. 「预约管理」查看并修改预约状态为「已完成现场采血」
9. 普通用户提交「献血过程评价」「身体异常反馈」
10. 管理员在「异常反馈管理」处理反馈
11. 管理员在「统计首页」查看数据卡片与 ECharts 图表
12. 管理员在「外部接口演示」点击模拟调用，查看返回数据与调用日志

## 五、接口模块一览（前缀 `/api`）

| 模块 | 说明 |
| --- | --- |
| `/auth` | 注册、登录、当前用户、退出 |
| `/donor` | 献血者个人信息 |
| `/appointments` | 预约：创建 / 我的 / 详情 / 取消 / 管理端列表 / 改状态 |
| `/health-surveys` | 健康征询表：提交 / 我的 / 管理端列表 / 详情 |
| `/group-applications` | 团体申报：提交 / 手机号查询 / 管理端列表 / 改状态 |
| `/feedbacks` | 异常反馈：提交 / 我的 / 管理端列表 / 改状态 |
| `/evaluations` | 献血评价：提交 / 我的 / 管理端列表 |
| `/stats` | 统计卡片、预约状态分布、每日趋势、献血类型、反馈状态 |
| `/external` | 外部系统占位接口（电子签名 / 采供血 / 微信 / 智慧招募），返回模拟数据并写日志 |

## 六、第一版边界

仅实现可演示的业务闭环，**不做**真实微信登录、短信验证码、电子签名、采供血系统对接、复杂权限与审批、线上部署等；外部系统接口仅返回模拟数据用于证明系统结构完整。
